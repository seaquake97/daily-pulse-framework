# 决策卡七件套规范

每条研判必须是一张完整的决策卡。七项缺一 → CI 打回重写。
评级必须与 compute_signals.py 输出的 Σ 计算值一致，LLM 不得上调/下调。

```markdown
### 🎯 决策卡 | <标的或组合名> | <YYYY-MM-DD>

1. **方向**：<进攻 / 均衡 / 防守 / 回避>（Σ=<值>，代码计算，禁改）
2. **偏离幅度**：相对沪深300 <+/-X.XX pct>（代码计算：标的涨跌幅 - sh000300 涨跌幅）
3. **持有期**：<N> 个交易日（<YYYY-MM-DD> 前有效，到期自动作废；持有期必须覆盖
   至少一个已知数据日历事件，禁止"永远有效"）
4. **触发条件**：若 <可验证指标 X：成交额/涨停家数/量比/两融/行业资金/具体价位> 验证，
   则 <具体动作：加仓X%/减仓X%/挂单Y元/启动网格第N档>
5. **失效条件**：若 <可验证指标 Z> 出现，则撤销本判断，<回落到的默认状态>。
   **失效条件强制非空**——未填写即 CI 打回
6. **赔率区间**：<前瞻赔率 = |目标价-现价| / |现价-止损价|，代码计算；历史分位
   P25~P75 为辅助>；样本<20 显示"样本积累中"，**LLM 禁止报任何赔率数字**
7. **数据日历**：明日 <宏观数据/财报/解禁/事件>；本观点有效期至 <日期>
```

## 差异化展示要求（防"十张卡同一个结论"）

- 组合层 TOP 3 决策卡按 |偏离幅度| 降序展示，读者先看分歧最大的
- 持仓诊断必须区分处理：触及网格触发线的列"动作卡"，未触及的列"观察卡"（写明距
  触发线距离），禁止全部并列成同一语气
- 连续两个交易日立场票数不得相同；非单边行情下，方向 3 日内不得恒定

## 四档评级 → 标准动作映射（基金/组合层）

| 评级 | Σ 区间 | 标准动作（可被触发条件微调，不可反向） |
|------|--------|--------------------------------------|
| 进攻 | ≥0.50 | 定投额度上浮 ≤20%；网格卖单档位可上移；单日新增买入 ≤ 总仓位 5% |
| 均衡 | 0.15~0.50 | 定投基准额度；网格按原参数运行；不主动加减仓 |
| 防守 | -0.50~-0.15 | 暂停一切主动买入（含手动追加），定投可降档 ≤30%；只挂更低吸买单；卖出仅在触发线执行 |
| 回避 | ≤-0.50 | 定投暂停一期；持仓亏损 >15% 的品种执行减仓 ≤1/3（分笔）；启动防御仓（红利/黄金）再平衡 |
| 信号矛盾 | \|Σ\|<0.15 或有效权重<0.50 | 暂停一切主动买入；可挂低于现价≥2%的吸买单；只列多空双方证据 + 明日待验证信号；禁止表述为"均衡" |

## 持仓个股/ETF 层决策卡附加项

- **网格状态**：现价 vs 基准价偏离 X%，距上一档触发线 Y%
- **底仓红线**：可用份额 vs 最小底仓（触及即停卖）
- **当日具体委托**：挂买价格/数量 或 挂卖价格/数量 或 不挂单及理由

## 观点台账（viewpoint.json）生成规则

当日每条条件性判断必须落档：

```json
{
  "date": "YYYY-MM-DD",
  "verdict": {"rating": "防守", "sigma": -0.28},
  "viewpoints": [{
    "id": "V1",
    "claim": "人话版结论（报告里展示的那句）",
    "type": "conditional",
    "condition": {"metric": "total_amount_yi", "op": "<", "value": 15000},
    "action": "暂停主动买入",
    "status": "pending"
  }]
}
```

- `metric` 可用：`total_amount_yi`、`idx:<代码>.<字段>`、`mb:<up|down|limit_up|limit_down>`、
  `hd:<代码>`（持仓现价，代码为 sh/sz 前缀格式）
- **考核时点声明**：每条条件必须带 `"eval_at": "close" | "intraday"`。盘中任务
  （9:28/11:00/14:30）只能用 intraday 条件且阈值按时段折算（例：半日成交额阈值=
  全日阈值×0.5）；收盘任务（15:05 之后）用 close 条件。防止"半日 6857 亿 < 全日
  1.5 万亿"式误触发
- 次日由 settle_viewpoints.py 自动结算，报告必须展示"昨日观点兑现"小节
- **四态结算**：TRIGGERED（条件触发）/ NOT_TRIGGERED（未触发）/ UNEVALUABLE（数据缺失）
  / **MISSED_NEUTRAL（漏报）**——若昨日出具"中性/无观点"单，而期间指数波动代理
  （|沪指涨跌|+|沪深300涨跌|）超过 1.0pct，记为"漏报"并披露。骑墙必须被定价
- **append-only 防篡改**：settlement.json 只追加不覆盖；viewpoint.json 落档后不得修改
- **三维分统**：命中率按（方向 / 指标类型 / 持有期）三个维度分别统计，禁止只报总命中率
