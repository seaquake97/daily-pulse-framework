# 信号评分细则（S1-S6）

全部由 `scripts/compute_signals.py` 计算。LLM 禁止手工调分、禁止"我觉得应该更高"。
缺失信号自动从归一化权重中剔除（例：S5 数据缺口 → 剩余 5 个信号按 0.85 权重归一）。

**有效权重封顶（v1.2）**：有效权重 < 0.50（过半信号缺失，如仅剩 S1+S2=0.40）时，
评级强制封顶为「信号矛盾」，verdict 置 `data_insufficient=true`——单一信号不得主导
方向性结论；该档只允许列多空证据 + 数据缺口清单 + 明日待验证信号。

## S1 量能（权重 0.20）

- 输入：沪指量比 `volume_ratio`（data_quote，相对过去5日同时段归一化，盘中/收盘通用）
- 公式：`S1 = clamp((量比 - 1.0) / 0.8)`，即量比 1.8 饱和 +1、0.2 饱和 -1
- 口径：>2 万亿正常活跃；1.5-2 万亿温和；<1.2 万亿定义为"缩量"（不用"天量"，金融口径从严）
- 说明：v1.1 起弃用"半日成交额/20日均值"（盘中时段对比全日均值必然失真）；标度 0.8 防封顶主导 Σ
- 数据缺口：量比缺失 → S1 剔除，报告标注"量能信号缺失"

## S2 宽度（权重 0.20）

- 输入：`data_changedist` 的 upCount/downCount/limit_up/limit_down
- 公式：`S2 = clamp((上涨占比-0.48)/0.16*0.7 + clamp((涨停-跌停)/50)*0.3)`
- 宽度项 ±0.16 饱和（上涨占比 32% ≈ 弱宽度满格 -1）；涨跌停项 /50 归一（涨停-跌停=50 贡献满格）
- 口径：涨停>80 且跌停<5 为情绪极值区（反向信号，报告中单独提示）

## S3 动量（权重 0.15）

- 输入：上证 price vs MA5/MA20（data_kline close）+ 20 日涨跌幅（data_quote chg_20d）
- 公式：`0.5*clamp((price/MA5-1)/0.02) + 0.5*clamp((price/MA20-1)/0.04) + clamp(chg20/5)` 取平均
- 价格在 MA20 下方 4% 以上 = 动量 -1

## S4 分化（权重 0.15）

- 输入：创业板指 + 科创50 涨跌均值 vs 沪深300 涨跌
- 公式：`S4 = clamp(价差/2.0)`；成长跑输蓝筹 2pct = -1
- 意义：捕捉风格切换（如今日科创50 -1.20% vs 沪深300 -0.23% = 成长失血）

## S5 资金（权重 0.15）

- 输入：板块主力净流入 TOP1 - 净流出 TOP1（data_sector/data_fund_flow）
- 公式：`S5 = clamp(净差/50亿)`
- 数据缺口：MCP 板块资金不可得 → S5 剔除并标注

## S6 估值（权重 0.15）

- 输入：沪深300 PE（data_quote pe_ratio）+ 60 日涨跌幅（chg_60d，超跌代理）
- 公式：`S6 = clamp((15-PE)/3 + clamp(-chg60/10)*0.5)`
- PE<12 便宜 +1；PE>18 偏贵 -1；60 日跌 10% 额外 +0.5（超跌反弹分）

## 四档评级与阈值

```
Σ ≥  0.50  进攻      （做多窗口：定投上浮≤20%、网格卖档上移、新增买入≤总仓位5%）
 0.15~0.50 均衡      （基准定投+网格原参数，不主动加减仓）
-0.15~0.15 信号矛盾  （暂停主动买入；可挂低于现价≥2%吸买单；只列多空证据+明日待验证信号；禁止表述为"均衡"）
-0.50~-0.15 防守     （暂停主动买入、定投可降≤30%、只挂更低吸买单）
Σ ≤ -0.50  回避      （定投暂停一期、浮亏>15%品种分笔减≤1/3、防御仓再平衡）
```

有效权重 < 0.50 时（v1.2 封顶规则）：无论 Σ 正负，评级一律【信号矛盾】+
`data_insufficient=true`，禁止输出进攻/均衡/防守/回避任何方向档。

## 反滥用设计

- Σ 由代码写入 market_data.json 的 `verdict` 字段；validate_market_data.py 断言 verdict 存在
- LLM 在报告中引用 Σ 必须原样引用，禁止四舍五入到"约 0.3"或改述为"偏正面"
- 信号矛盾档是独立状态：只允许列多空证据清单 + 明日待验证信号，禁止给方向
