# 专家团对抗辩论协议（信息隔离 + CIO 裁决）

适用：股票复盘（15:05）、每日总复盘（15:30）、复杂行情日的股票助手（9:28）。
参考范式：TradingAgents 分析师→牛熊辩论→PM 分层；openInvest 信息隔离契约。

## 接入方式

任务提示词中显式拉起专家（WorkBuddy 专家团 stock-partner-team）：

- **分析师层**（并行，互不可见，各自只拿本维度数据）：
  - 技术面：`technicals-analyst`（K线/均线/量能/技术指标）
  - 基本面：`fundamentals-analyst` 或 `warren-buffett`（持仓个股财报口径）
  - 资金情绪：`sentiment-analyst` + `news-sentiment-analyst`（板块资金/新闻情绪）
  - 估值：`valuation-analyst` 或 `aswath-damodaran`（PE 分位/DCF 代理）
- **对抗层**（拿全部分析师报告）：
  - 牛方：`cathie-wood` 或 `growth-analyst`（强制找多证据，≥2 条可验证）
  - 熊方：`michael-burry` 或 `contrarian-investor`（强制找空证据，≥2 条可验证）
  - 两轮制：第一轮各自举证 → 互换报告 → 第二轮互相反驳（openInvest Round 2 Rebuttal）
- **裁决层**：`portfolio-manager`（CIO）综合，输出结构化裁决：
  `评级（进攻/均衡/防守/回避/信号矛盾）+ 置信度（高/中/低）+ 关键分歧点`
- **风控闸口**：`risk-manager` 对 CIO 裁决做仓位/回撤合规检查，可否决

## 信息隔离红线（防禀赋效应与锚定）

1. 技术/信号/情绪分析师**禁止提前获知持仓盈亏与成本**——只给行情与市场数据
2. 牛熊辩论阶段才注入持仓事实（此时举证已成型，避免"因为亏了所以看多"）
3. CIO 裁决必须显式区分"市场判断"与"持仓处置"两段，不允许混写
4. 任何专家引用数据必须带"来源+时点"，引用持仓数字必须来自 parse_holdings.py 输出

## 成本与降级

- 完整团（4 分析师 + 牛熊 + CIO + 风控）约 8-10 次专家调用，仅用于 15:05/15:30 两个复盘任务
- 9:28 竞价分析、11:00 基金盘面：不拉团，用 compute_signals.py 评级 + 决策卡即可
- 专家调用超时/失败 → 跳过辩论走简化链，但代码评级与决策卡七件套仍必须完整
- 连续 2 次辩论结论与 Σ 评级方向相反 → 以 Σ 为准（代码确定性优先），并在报告中披露分歧

## 专家观点呈现规范

- 报告中的专家观点统一标注 🤖 AI 研判点评，禁止虚构具体人名
- 每位专家输出必须包含：结论句 + ≥2 条可验证证据 + 1 条失效条件
- 观点台账：专家条件性判断同步写入 viewpoint.json 参与次日结算
