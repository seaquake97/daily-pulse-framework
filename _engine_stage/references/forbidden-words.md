# 中性词禁令与套话黑名单

CI 第 1 关：禁词扫描。三类全部 0 命中才允许发布。命中 → 重写对应段落，
禁止用"基本上/一定程度上"等缓冲词蒙混过关。

## 双阈值联检机制（防对抗性绕过）

单纯查词会被同义词替换绕过（"稳中向好"→"稳字当头"）。CI 采用**双阈值联检**：

```
IF 中性词密度 > 1.5 次/千字 AND 数值密度 < 验收线 → 打回重写
```

- **数值密度**：每千字决策段中"可验证数值"（价格/百分比/日期/金额/家数）个数，
  验收线 ≥4 个/千字
- **句式模式匹配**（正则，防同义词替换）：
  - `维持.{0,4}(既定|现有|当前)`、`保持.{0,4}(既定|现有)`、`无需.{0,6}干预`
  - `建议(关注|留意)`、`耐心等待`、`静待`、`边走边看`、`或将继续`、`有望`
- **一级词**（硬阻断）：A 类全部 + 上述句式
- **二级词**（警告，全篇 ≤3 次）：`或`、`关注`、`观察`、`择机`
- 每月人工抽审 1 次对抗样本（同义词替换攻击测试）

## A 类：结论级中性词（出现即打回）

| 禁词 | 问题 | 替代写法 |
|------|------|---------|
| 维持既定 / 保持既定 / 按既定计划 | 把决策外包给"计划"，等于没有决策 | 给出今日具体动作：`加仓X%/减仓X%/仅挂买单Y元/暂停Z` |
| 无需手动干预 | 99% 的每日报告都写这句，信息量为零 | 写"干预触发线：价格到 X 才动作；今日未到线，故不动"——把"不动"变成有条件的判断 |
| 系统性风险可控 | 不可证伪的万能句 | 用量化指标替代：`跌停仅4家+上涨占比31%+成交1.4万亿=短期无系统性抛压` |
| 稳中向好 / 震荡整理 / 结构性行情 | 遮日期盲测必然命中的套话 | 描述具体结构：`资金从科创50(-1.20%)切向北证50(+1.36%)` |
| 建议关注 / 值得重点关注 | 无触发条件的方向词 | `若X站上Y则关注Z，否则不参与` |
| 耐心等待 / 静待观察 / 边走边看 | 逃避决策 | `等待对象=具体价位/信号+等待期限+等待失效后的动作` |
| 或 / 有可能 / 大概率将继续 | 模棱两可双句式 | 二选一：主判断+备选路径（各带触发条件），禁止"可能A也可能B"式并列 |
| 不悲不喜 / 谨慎乐观 / 谨慎观望 | 心态描述不是决策 | 删除，换成仓位/价格判断 |

## B 类：伪装成分析的填充语（出现即打回）

- 综上所述 / 总而言之 / 值得一提的是 / 不难发现 / 由此可见
- 在政策红利持续释放的大背景下（无具体政策名称与日期）
- 中长期景气度未改（无数据支撑的长逻辑复读）
- 充分发挥了压舱石/防御属性（自夸式总结，无当期数据）
- 一方面……另一方面……（和稀泥结构）

## C 类：数据与合规红线（出现即一票否决）

- 任何未标注来源与时点的行情数字
- 用指数涨跌冒充基金估值（必须标注"估值源缺失，参考标的指数表现"）
- "建议买入/卖出/满仓/清仓"等指令性动词裸奔（必须包在"若X→则Y"条件句内）
- 昨日观点未结算就下新结论（观点台账必须先行）
- 遮住日期后依然完全成立的段落（盲测不过 → 重写）

## 有效性自检

每段结论写完后问三个问题：
1. 删掉日期，这段话还能原样用在别的日子吗？→ 能，重写
2. 这段话告诉读者"什么价格做什么动作"了吗？→ 没有，重写
3. 这段话的措辞换成反义词（涨↔跌），逻辑还通吗？→ 通，说明没有信息量，重写
