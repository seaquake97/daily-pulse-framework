# 团队协作纪律 v1.0（2026-10-17 事故后修订）

> 事故：2026-10-17 下午，4 名金融专家 agent 消耗约 700 积分、25 轮交叉讨论，产出为「大量对话、0 行代码、0 条断言」，且全程 agent 之间直接通信、无人把关。
> 本文档为**强制纪律**，违反 = 任务作废重派，不是建议。

---

## 一、四条铁律（违反即中止任务）

### 铁律 1：禁止 agent 之间直接通信
- 所有跨成员信息流**必须经我（总监）中转**。成员之间不得 SendMessage 互聊。
- 原因（本次实证）：4 个 agent 直连后形成**回音室**——同一论点被反复确认 25 轮，越聊越自信，实际产出为零。直连让每个成员都以为「已经有人在做」，于是都去做「讨论」而非「交付」。
- 成员完成后**只能**回传给我，由我判断是否需要转达给下一位。

### 铁律 2：任务书必须写死「交付物 + 验收命令」，无交付物的任务不予下发
每个成员任务书必须包含且缺一不可：
1. **交付物清单**（具体文件路径，不接受「方案」「建议」「评估报告」这类无文件名交付）
2. **验收命令**（可机械执行的命令 + 期望输出）
3. **禁止事项**（禁止 git commit/push、禁止跨成员通信、禁止扩展范围）
4. **轮次上限**（默认 1 轮；确需追问由我发起，不得自行连续讨论）

### 铁律 3：禁止「先讨论后实现」，必须「先实现后校验」
- 成员的第一份产出必须是**代码/数据/文档文件**，不是观点。
- 「评估」「评审」「合理性分析」类任务必须绑定一个**可执行产物**（如：把评估结论写成 schema 字段、写成测试用例、写成校验器规则）。纯文字评估不予下发。

### 铁律 4：成员必须先核查已有资产，不得从零设计
- 下发任务前必须由我提供**现有实现清单**（文件路径 + 已具备能力）。
- 成员 prompt 中必须写明「先读这些文件，已有的能力直接复用，不要重新发明」。
- 本次事故的一个直接成因：4 个 agent 各自从零设计数据仓/规则体系，而仓库里 `config/portfolio.yaml`、`framework/scripts/rules*.py` 早已存在。

## 二、积分预算纪律

| 规则 | 说明 |
|---|---|
| **先估算后下发** | 单个成员任务预估 > 100 积分时，必须先向我说明为什么不能用更小任务替代 |
| **单任务上限** | 单个成员任务默认上限 1 轮；超轮需我书面批准 |
| **禁止「专家团」默认启动** | 「召唤专家团评估」是高成本动作。必须先回答：<br>① 这个评估的结论会改变什么代码/文件？<br>② 改变的话，改动落在哪个文件？<br>③ 若答案是「只是更清楚」，则**不发任务** |
| **对话不算产出** | 任何任务若结束时「可执行文件新增数 = 0 且现有文件修改数 = 0」，视为未完成，积分不予计入成果 |

## 四、成员任务的强制模板

```
【交付物】（缺一不可，全部为可执行文件）
1. <文件路径> — <一句话说明它做什么>
2. ...

【验收命令】（必须可机械执行，附期望结果）
$ python3 <脚本> <参数>   → 期望：退出码 0 / 输出含 XXX

【硬约束】
- 纯标准库零第三方依赖；单文件 ≤300 行
- 禁止 git commit / push（由我统一提交）
- 禁止与其他成员直接通信（信息经我中转）
- 禁止扩展到本任务范围外

【先读这些】（我提供，指明已具备的能力，禁止重复发明）
- <文件>：<它已经能做什么>
- ...

【轮次】1 轮。有疑问写在回传报告里，不要自行发起讨论。
```

---

## 五、回传格式（成员一律使用）

```
verdict: pass | fail
交付物: <文件路径> × N（含行数）
验收: <命令> → <实际输出摘要>
复用: <复用了哪些已有资产>
未解决: <需要我裁定的问题，单条列出>
```

**禁止**在回传里写长篇论证、禁止复述他人观点、禁止提出新任务建议。有问题就一句话列出来，我来决定。

## 六、本次事故的收割原则

25 轮讨论**不是全无价值**，其中可保留的硬结论已由我收割进 `docs/EXPERT-REVIEW-HARVEST.md`，后续成员必须先读该文件，**禁止重新讨论已收割的议题**。

| 保留类型 | 处理 |
|---|---|
| 与真实数据冲突的结论 | 丢弃（本次：卫星ETF 归入「算力链」、华能蒙电归入「绿电链」，均与实际主营不符） |
| 需要实时行情才能验证的结论 | 标记 `unverified`，不进代码，只进待办 |
| 可机械化的纪律 | 转成本次任务的具体字段/断言（本次：已写入铁律 1-4） |
| 方法论层面、纯观点 | 归档不实施（本次 25 轮里绝大多数属于此类） |
