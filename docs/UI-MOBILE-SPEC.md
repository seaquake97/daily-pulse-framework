## 一、设计基准与风格哲学

本项目严格遵循 **Apple 风格设计系统（Apple HIG 规范）**：
- **微质感、零卡片阴影杂乱、零花哨渐变**；
- **深浅双模自适应**，纯粹依赖 `hairline`（细微线框）与面底反差构筑层次；
- **100% 恪守团队三大 P0 绝对红线**：
  1. **P0-1：严禁使用 emoji 作为功能图标**（所有图标必须为系统内联 SVG Symbol，描边 1.75~2px 保持一致）；
  2. **P0-2：严禁紫粉渐变主视觉**；
  3. **P0-3：严禁硬编码颜色字面量**（唯一例外 #fff/#000），一切走设计 Token。

## 三、三级手风琴视觉规范细节

### 3.1 一级：日期卡片（`.day-accordion`）
- 容器：基于 `.dp-card`，边框 `1px solid var(--border)`，圆角 `var(--r-card)`（14px），背景 `var(--surface)`。
- 头部（`.day-summary`）：
  - 高度：`52px`，单手触控热区；
  - 布局：Flex 两端对齐，左侧为日期时间 `var(--fs-headline)` 加粗，右侧为当日综合评级与 Σ；
  - 展开指示：右侧悬挂原生或定制内联 Chevron 图标，展开时平滑顺时针旋转 180 度（`transform: rotate(180deg)`）。
- 折叠策略：
  - 首个日期（今天）带 `open` 属性，默认展开；
  - 历史日期不带 `open`，默认折叠收起。

### 3.2 二级：时点卡片（`.slot-accordion`）
- 容器：在日期展开区内，每个时点为一个微卡片，边框 `1px solid var(--border-subtle)`，圆角 `var(--r-base)`（10px），下间距 `var(--space-2)`。
- 头部（`.slot-summary`）：
  - 高度：`48px`；
  - 布局：Flex 两端对齐；
  - **左侧**：
    - 时点时间（`09:28`）加粗；
    - 任务名称（`股票竞价` / `基金盘面` / `基金指引` / `每日复盘`）中性字色，**剔除重复的年月日与星期**；
  - **右侧**：
    - **单一状态药丸（Status Pill）**：
      - 正常状态：`<span class="rating ...">`（评级徽章，如 `进攻 ▲▲`）；
      - 降级状态：`<span class="tag tag-degraded">⚠️ 数据降级</span>`；
      - **绝对禁止在此处堆叠 5 个同义标签**！
    - 折叠指示箭头（Chevron）。

### 3.3 三级：展开内容区（`.slot-body`）
- 内边距：`var(--space-3) var(--space-4)`；
- 内容层级：
  1. **第一视觉**：核心指令块（`.slot-action`），背景微浅底色（`var(--surface-alt)`），加粗呈现操作指令；
  2. **第二视觉**：精炼事实与佐证，文字字号 `var(--fs-subhead)`（14px），行高 `1.4`；
  3. **第三视觉**：完整报告跳转大按钮（`.slot-link-btn`），高度 `42px`，全宽大圆角按钮，点击跳转至对应 `daily/{date}/{slug}.html`。

## 四、CSS 响应式与动画规范

```css
/* 手风琴原生清除默认标记 */
.day-accordion > summary,
.slot-accordion > summary {
  list-style: none;
  cursor: pointer;
  user-select: none;
  -webkit-tap-highlight-color: transparent;
}
.day-accordion > summary::-webkit-details-marker,
.slot-accordion > summary::-webkit-details-marker {
  display: none;
}

/* 展开平滑旋转箭头 */
.accordion-chevron {
  transition: transform 0.25s cubic-bezier(0.2, 0, 0, 1);
  color: var(--fg-muted);
}
details[open] > summary .accordion-chevron {
  transform: rotate(180deg);
}

/* 底部防遮挡安全边距 */
.content-wrapper, main {
  padding-bottom: max(var(--space-16), calc(env(safe-area-inset-bottom, 24px) + var(--space-8)));
}
```
