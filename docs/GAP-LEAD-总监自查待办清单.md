## L-2 · 旧脚本去 /tmp 依赖

`fetch_data.py` 写 `/tmp/market_data_cache.json`，`generate_report.py` 读它。
/tmp 会被系统清理 → 读到不存在的缓存时行为不确定。

**修法**：中间产物落 `<任务目录>/<日期>/`。
**前置**：需先决定这两个脚本的存废（见 GAP-ARCH 的「删除重写 vs 标注不可用」）。

## 经验记录（本轮踩坑，可复用）

| 坑 | 教训 |
|----|------|
| 校验器误报比漏报更危险 | 「昨日观点：6.75 元挂买」是回顾不是动作；契约一旦变噪音就没人看 |
| 表格行不能整体豁免 | 实测动作藏在网格卡表格里，豁免表格等于放过真 P0 |
| `TemporaryDirectory()` 不是"不存在路径" | 它确实存在，`is_dir()` 为真；须用 `td/no-such-x` |
| 相对路径在 subprocess 里随 cwd 失效 | 子脚本路径须用 `Path(__file__).resolve()` 派生的绝对常量 |
| 环境变量须在函数内解析 | 用导入时模块常量会导致外部覆盖失效、缺依赖漏检 |
| 内联列表/行尾注释在极简 YAML 解析器里是隐形坑 | 两者都让规则「看起来正常实则已死」，且无任何报错 |
| 契约要服从产品，不能反过来 | 降级提示排在结论之前是对的（读者先知数据不可信），一度被契约误判 |
