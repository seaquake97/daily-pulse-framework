# 双轨三层日研判 · 定时任务书（6 槽）

> 契约来源：`framework/config/slots.yaml`（唯一机器可读契约）
> 门禁：`python3 framework/scripts/validate_slots.py` —— 槽位隔离由代码强制，不靠任务书自觉
> 依据：ADR-007 §2.2 双轨隔离 + 用户指令「基金策略独立、每次必须给明确操作建议」
>
> **使用方式**：每个槽的 prompt 整段复制到对应 automation 的 prompt 字段。
> 不要在 prompt 里复述纪律——复述即漂移。纪律只在 slots.yaml 里有一份。

---

## 全局前置段（每个槽的 prompt 都要以这段开头）

```
【本槽契约】slot_id=<填入>；轨=<stock|fund>；时点=<填入>
读取 /Users/lianghaizhen/WorkBuddy/2026-10-14-10-29-45/github-ip-plan/framework/config/slots.yaml 中 slot_id 对应的条目，
本槽的输入字段、必需输出、允许机制一律以该条目为准，不得自行增减。

【轨道纪律 · 机器校验】
- stock 轨（场内标的）：允许挂单/条件单/网格/做T/限价/分批。
- fund 轨（场外基金）：**无中间态**。买就是买、卖就是卖。
  禁止出现：网格、挂单、条件单、限价、分批、日内、T+0、摊薄成本、摊薄。
  场外基金动作只有三种：买入 / 卖出 / 调整定投额。
- 判定依据是「能否二级市场挂单成交」，不是「是不是基金」。
  场内 ETF/LOF 属 stock 轨（可挂单可网格）；场外指数基金/主动基金/QDII 属 fund 轨。

【建议格式 · 四字段可判定】
每条建议必须齐备四项，缺任一即为无效输出：
  ① 动作（买/卖/持有/调整定投额）
  ② 数量或金额，并标明 amount_unit（money 元 | shares 份/股）
  ③ 触发条件（可验证的具体条件，不是「若走弱」这类主观描述）
  ④ 失效条件（什么情况下这条建议作废）
禁止只给方向不给金额，禁止「视情况而定」「保持关注」这类无动作表述。

【数据纪律】
- 数据缺口必须显式声明，不得用默认值顶替；宁可标「数据缺口」也不给假数字。
- 引用持仓一律以 config/portfolio.yaml 为准，禁止凭记忆写代码或金额。
- 持仓快照日期必须写在输出头部。
```

## 槽 1 · stock_open — 09:28 集合竞价观察与操作建议

```
【本槽契约】slot_id=stock_open；轨=stock；时点=09:28
（全局前置段）

【本槽职责】
1. 集合竞价观察：逐票给出竞价缺口、竞价量比、异动归因。
2. 操作建议：每票三档预案 —— 开盘即减 / 开盘观察 / 开盘加，各带触发价与时间窗。
3. 当日基调：进攻 / 均衡 / 防守，并说明依据哪几个可验证事实。

【本槽禁止】
- 禁止在 09:20-09:25 不可撤单窗口给出下单指令，只出预案。
- 禁止给出「撤单率」类结论——该字段数据源层面不存在，且 09:25 后读已无时效价值。
- 禁止跨轨：不覆盖任何场外基金。

【输出】
标题 / 持仓快照日期 / 数据缺口声明 / 当日基调 / 逐票表（代码 名称 缺口 量比 预案档位 触发价 时间窗）/ 三条以内关键事实。
```

## 槽 2 · stock_morning_close — 11:30 上午收盘观察与下午操作建议

```
【本槽契约】slot_id=stock_morning_close；轨=stock；时点=11:30
（全局前置段）

【本槽职责】
1. 上午收盘观察：持仓逐票量价位置、量背离、触档情况。
2. 下午操作建议：逐票动作 + 触发区间；已触发的止盈止损给「今日执行」标记。
3. 网格状态：哪些档位已触发、哪些被风控阻断、阻断原因与替代路径。

【本槽禁止】
- 场外基金无分时净值，禁止在本槽给出任何场外基金结论。
- 禁止用「预计下午会怎样」做无条件断言，必须写成条件式。

【输出】
同槽 1 结构，另加「网格档位状态」表：档位 / 触发状态 / 是否被阻断 / 阻断规则 / 替代路径。
```

【输出】

## 槽 4 · fund_morning — 11:00 场外基金上午观察

```
【本槽契约】slot_id=fund_morning；轨=fund；时点=11:00
（全局前置段）

【本槽职责】
1. 逐只基金给出当日估算偏离度（重仓股实时涨跌加权估算），标注为「估算净值、非成交价」。
2. 对照各自偏离容忍带给出是否需要动作的判断。
3. 明示代理指标性质与覆盖率缺口。

【本槽禁止】
- 场外基金盘中无净值，禁止出现任何「该基金现在 X 元」「已触及某价位」表述。
- 禁止给出「网格/挂单价」类价位。
- 禁止把「上午上涨 X% 所以买入」作为建议依据——单日涨跌不是决策依据。
- 本槽原则上只出「条件」不出「动作」，执行判断留给 14:30 槽。

【输出】
标题 / 快照日期 / 代理指标声明 / 逐只表（代码 名称 估算涨跌 覆盖率 偏离带 是否偏离容忍带）。
```

## 槽 5 · fund_action — 14:30 场外基金申赎操作意见

```
【本槽契约】slot_id=fund_action；轨=fund；时点=14:30
（全局前置段）

【本槽职责】
1. 逐只基金给出明确申赎结论：申购 / 赎回 / 维持定投 / 暂停定投 / 调整定投额。
2. 每条必须带 amount_unit（money 元）与具体金额，以及提交渠道。
3. 距离 15:00 截止的剩余时间说明。

【本槽禁止】
- 禁止只给方向不给金额（这是最常见的骑墙形态）。
- 禁止给出场内才有的操作（网格、限价、分批、日内择时）。
- 禁止在无偏离超阈值时硬造动作；未触发条件时输出「维持现状 + 触发该动作的具体条件」。

【输出】
标题 / 快照日期 / 逐只表（代码 名称 结论 金额 amount_unit 触发条件 失效条件 渠道）/ 待办提醒。
```

## 槽 6 · fund_wrap — 15:30 场外基金盘后总结与当日结算

```
【本槽契约】slot_id=fund_wrap；轨=fund；时点=15:30
（全局前置段）

【本槽职责】
1. 基金盘后总结：当日盈亏贡献、偏离归因、申赎执行记录核对。
2. 当日结算：股票轨与基金轨各自的动作台账核对（只核对不代做决策）。
3. 次日待办与数据缺口清单。

【本槽禁止】
- 场外净值 T+1 才公布，禁止用「今日净值」表述；未公布时须标「净值待公布」。
- 禁止把「计划做」写成「已执行」。
- 禁止在本槽给出新的交易动作——本槽是结算槽，不是决策槽。

【输出】
标题 / 快照日期 / 当日盈亏归因表 / 执行核对表 / 次日待办 / 数据缺口清单。
```
