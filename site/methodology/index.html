研判方法论

每一条结论的生产轨迹都写在这里：数据硬校验 → 代码化信号评分 → 双重金融护栏 → 专家圆桌对抗辩论 → Σ 评级。
Every conclusion follows one deterministic pipeline — same data in, same verdict out.

01决策引擎七步流水线 / Seven-Step Pipeline

01交易日判定
02数据采集
03信号评分
04持仓解析
05硬校验
06专家辩论
07决策落档
  1. 交易日判定：经交易日历确认目标日为 A 股交易日；非交易日静默结束，不产出。
  2. 数据采集：行情、板块资金、涨跌分布、估值等全部经腾讯自选股 MCP（westock-mcp）实时获取，禁止写死数值或凭记忆填数。
  3. 信号评分：S1-S6 六信号由代码计算并合入 verdict 字段，LLM 禁止手工调分。
  4. 持仓解析：持仓与网格参数从本地记忆文件动态解析，代码与提示词中不写死任何持仓数据。
  5. 硬校验：数据完整性断言任一失败即停产出，标注缺口清单，禁止带脏数据出报告。
  6. 专家研判：六位虚拟专家（产业/信号/估值/逆向/财报/短线维度）多空对抗辩论，观点须引用当日数据。
  7. 决策卡落档：结构化决策卡与观点台账归档，供后续准确率结算与连续错误熔断。

顺序即契约：先信号评分、后硬校验——校验器强制要求 verdict 存在，顺序颠倒会直接零产出；同一条链路每日重复执行，输出可复现、可回归。

04技术指标与动态补偿 / Technical Indicators

指标计算为纯确定性算法（纯标准库实现、零第三方依赖），结果可复现、可回归，不随模型推理变化。

  • 均线系统（MA）：MA5 / MA10 / MA20 / MA60 滑动平均，用于趋势状态判定与动态支撑阻力识别。
  • 乖离率与强势补偿（BIAS）：BIAS = 现价 / MA − 1。基础阈值 5%（严进纪律，抑制追高）。强势趋势补偿机制：当标的处于确认的强势趋势（STRONG_BULL）时，有效阈值自动放宽 1.5 倍至 7.5%，允许在主升浪中顺势追踪、避免机械踏空；但乖离率超过放宽后阈值仍一律判定追高风险，纪律底线不让步。
  • 平滑相对强弱（RSI）：采用 Wilder 平滑口径（SMMA）计算 6 / 12 / 24 日三档，规避简单平均导致的数值跳变；超买超卖与背离用于动量确认。
  • 指数平滑异同（MACD）：DIF = EMA(12) − EMA(26)，DEA = EMA(DIF, 9)，BAR = (DIF − DEA) × 2；金叉死叉与零轴位置、顶底背离共同参与结构判定。
  • 与 Σ 的分工：指标不替代六信号 Σ，而是在 S4 动量项中作为可选增强项介入（缺失时 S4 回退为纯成长/蓝筹分化口径，行为与基线一致）。

动态 BIAS 1.5×：强趋势下阈值 5% → 7.5% 是顺势追踪的补偿，不是纪律放松——越过放宽后的阈值，追高风险判定照常触发。

07多源容灾与断路器 / Multi-Source Failover

行情采集采用「主源 + 备用源」双链：主源健康时全量字段，主源故障时自动转移，任何一层都不虚构数据。

主源采集 Primary · westock-mcp

  • 腾讯自选股 MCP 实时提供行情、板块资金、涨跌分布与估值等全量字段。
  • 健康探测驱动链路状态；单次故障不切链，避免抖动式误转移。

备用容灾链 Fallback · 腾讯财经 / 新浪财经

  • 主源不可用时自动故障转移，单请求批量抓取全部持仓行情。
  • 备用源只提供指数与个股基础行情（现价、涨跌幅、成交额、成交量）；不虚构板块资金流与估值字段。

断路器纪律：连续 3 次失败熔断 300 秒，期间拒绝再试防打爆；主源优先、脏值丢弃、缺口声明绝不填 0、 degraded 结果绝不冒充主源——数据来源状态在报告头部显式标注。

08基金持仓穿透 / Fund Look-Through

基金侧不复用个股技术指标，而采用「持仓穿透 + 加权归因 + 缺口披露」三段式口径，与股票侧的 Σ 体系相互独立、互不串用。

  • 持仓穿透（look-through）：把基金净值拆解到十大重仓个股权重，再逐只采集实时行情，得到穿透后的实时行业暴露与集中度，而非仅看基金自身净值曲线。
  • 加权涨跌归因：组合加权涨跌 = Σ（个股权重 × 该股实时涨跌幅）。缺口披露纪律：估值覆盖率不足时，未覆盖部分一律剔除并显式标注覆盖率与缺口标的，严禁以指数涨跌或板块均值代理冒充真实持仓表现。
  • 板块集中度：对穿透后的行业分布计算集中度指标；主题型基金（如 CPO 主题）按实际持仓比例参与板块归并，比例缺失时全额计入「其它」并列出缺口基金清单，不用历史默认比例兜底。
  • 资产分层：主动权益、QDII 指数、红利低波与黄金防御四类资产分开评估，避免跨风格直接比较；QDII 需额外标注汇率与海外市场时滞影响。
  • 黄金处理：上海金等贵金属按宏观对冲资产单独列示，其涨跌与 A 股权益相关性低，不并入权益类加权归因。

09反滥用 · 合规 · 隐私 / Anti-Abuse & Privacy

  • 代码计算 Σ：Σ 由代码写入数据文件的 verdict 字段，报告引用必须原样呈现，禁止四舍五入或改述。
  • LLM 禁调分：语言模型不得修改任何信号分值，研判文本只解释代码结论。
  • 零编造：数据缺失明确标注「数据缺口」并降级，禁止用代理指标伪装真实值。
  • 信息隔离：持仓数据不参与信号评分输入，避免禀赋效应污染方向判断。
  • 观点台账：全部历史观点归档结算，连续错误触发熔断降级。
  • 数据时点标注：每期报告头部标注（竞价 / 盘中 / 收盘），不同时点的结论不可直接对比；缺少宽度口径标注时，Σ 值旁会显式提示不可跨时点比较。
  • 隐私边界：公开版本报告仅包含市场数据、信号评分与方法论；个人持仓金额、成本、盈亏与账户信息在发布前经自动化脱敏流水线移除，并经红线门禁校验（零命中方可发布）。

降级即禁言：数据源降级或缺口期，摘要层撤下标准动作与关键事实，只保留状态陈述——读者不会照着非实时数据算出的档位去下单。
